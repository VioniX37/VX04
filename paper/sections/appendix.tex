\section{Reproducibility}
\label{app:reproducibility}

All experiments are produced by \texttt{python -m evaluation.run\_benchmark} with the configs in \texttt{backend/evaluation/configs}; tables and figures by \texttt{python -m evaluation.analysis}. LLM responses are cached per seed, so re-running a config reproduces the same outputs.
